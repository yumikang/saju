## 1. 신생아 작명 서비스 (Naming)

### 📍 라우트 구조
- `/naming/freemium` - 프리미엄 V2 작명 서비스 (현재 활성)
- `/naming/history` - 작명 히스토리
- `/naming/favorites` - 즐겨찾기

### 🔄 워크플로우

```
┌─────────────────────────────────────────────────────────────────┐
│                   신생아 작명 서비스 워크플로우                  │
└─────────────────────────────────────────────────────────────────┘

STEP 1: 기본 정보 입력
┌────────────────────────────────┐
│ 👤 사용자 입력                 │
│ ─────────────────────────────  │
│ • 성(姓): 한글 + 한자 선택     │
│ • 생년월일: 양력/음력 선택     │
│ • 출생 시간: HH:mm            │
│ • 성별: 남/여                 │
│ • 부모 가치관 (선택)          │
└────────────┬───────────────────┘
             │
             ↓
┌────────────────────────────────┐
│ 📋 입력 검증                   │
│ ─────────────────────────────  │
│ • 필수 필드 확인              │
│ • 날짜 유효성 검증            │
│ • 성씨 데이터베이스 매칭      │
└────────────┬───────────────────┘
             │
             ↓

STEP 2: 사주팔자 분석 (Backend Pipeline - 8단계)
┌────────────────────────────────────────────────────────────┐
│ 🔮 STAGE 1: 사주(四柱) 계산                                │
│ ────────────────────────────────────────────────────────   │
│ • 음력 → 양력 변환 (필요시)                               │
│ • 절기(입춘) 계산                                         │
│ • 년월일시 → 천간지지 추출                               │
│   - 년주(年柱): 천간 + 지지                               │
│   - 월주(月柱): 천간 + 지지                               │
│   - 일주(日柱): 천간 + 지지 (일간 = 본인)                │
│   - 시주(時柱): 천간 + 지지                               │
│                                                            │
│ Output: 4개 기둥 (8개 글자)                                │
│ Example: 갑자년 병인월 무신일 계해시                       │
└────────────┬───────────────────────────────────────────────┘
             │
             ↓
┌────────────────────────────────────────────────────────────┐
│ 🎯 STAGE 2: 용신(用神) 분석 - 5방법 + AI                   │
│ ────────────────────────────────────────────────────────   │
│ • 오행 분석 (목화토금수 5개 원소)                         │
│   - 천간 오행: 갑을=목, 병정=화, 무기=토, 경신=금, 임계=수│
│   - 지지 장간: 숨은 천간 포함                             │
│                                                            │
│ • 용신 결정 (5가지 방법론)                                │
│   1. 억부법(抑扶法): 강약 균형                            │
│   2. 조후법(調候法): 계절 조화                            │
│   3. 통관법(通關法): 충돌 완화                            │
│   4. 병약법(病藥法): 문제 해결                            │
│   5. 전왕법(專旺法): 특화 강화                            │
│                                                            │
│ • AI 보조 분석 (OpenAI GPT-4)                             │
│   - 5가지 방법 종합                                       │
│   - 최종 용신(主) + 보조 용신(副) 결정                    │
│                                                            │
│ Output: 용신 = WOOD/FIRE/EARTH/METAL/WATER                │
└────────────┬───────────────────────────────────────────────┘
             │
             ↓
┌────────────────────────────────────────────────────────────┐
│ 📚 STAGE 3: 한자 추천 (용신 기반)                          │
│ ────────────────────────────────────────────────────────   │
│ • 용신 오행에 맞는 한자 필터링                            │
│   - 한자 DB (23,000+ 한자)                                │
│   - 오행 분류: 木火土金水                                 │
│                                                            │
│ • 안전성 검증 (다층 필터)                                 │
│   ✓ 성씨 보호: 132개 한국 성씨 제외                       │
│   ✓ 금기 한자: 12개 명시적 차단                           │
│     (愚,滯,重,尤,蹲,薯,猶,雖,猢,鵞 등)                     │
│   ✓ 부정 의미: Critical/High severity 한자 차단          │
│   ✓ 획수 데이터: 정확한 한자만 사용                       │
│                                                            │
│ • 성별 적합성                                             │
│   - 남성 선호 한자                                        │
│   - 여성 선호 한자                                        │
│   - 중성 한자                                             │
│                                                            │
│ Output: 용신 맞는 안전한 한자 풀 (300-500개)              │
└────────────┬───────────────────────────────────────────────┘
             │
             ↓
┌────────────────────────────────────────────────────────────┐
│ 🔄 STAGE 4: 이름 조합 생성                                 │
│ ────────────────────────────────────────────────────────   │
│ • 2자 이름: N × M 조합                                    │
│   - 첫째 글자 × 둘째 글자                                 │
│                                                            │
│ • 3자 이름: N × M × K 조합                                │
│   - 첫째 × 둘째 × 셋째                                    │
│                                                            │
│ • 최대 조합 수: 1,500개 (성능 최적화)                     │
│                                                            │
│ • 초기 필터링                                             │
│   - 같은 음절 반복 방지 (예: 민민, 수수)                 │
│   - 성과 이름 발음 충돌 체크                              │
│                                                            │
│ Output: 이름 후보 조합 (~1,500개)                          │
└────────────┬───────────────────────────────────────────────┘
             │
             ↓
┌────────────────────────────────────────────────────────────┐
│ ✅ STAGE 5: 종합 검증                                       │
│ ────────────────────────────────────────────────────────   │
│ 1. 음양오행 검증 (YinYangValidator)                       │
│    • 획수의 음양(홀/짝) 균형                              │
│    • 천격-인격-지격-외격-총격                             │
│    • 오행 상생상극 관계                                   │
│                                                            │
│ 2. 발음 검증 (PhoneticMatcher)                            │
│    • 초성-중성-종성 자연스러움                            │
│    • 받침 조합 난이도                                     │
│    • 발음 유사도 (중복 음 방지)                           │
│                                                            │
│ 3. 81수리 검증 (Numerology)                               │
│    • 사격(四格) 계산                                      │
│      - 천격: 성 + 이름 첫째                               │
│      - 인격: 이름 첫째 + 둘째                             │
│      - 지격: 이름 글자들                                  │
│      - 총격: 전체 획수                                    │
│    • 길흉 판단 (대길/길/평/흉/대흉)                       │
│    ⚠️  현재 비활성화 (데이터 부정확)                      │
│                                                            │
│ Output: 검증 통과 이름만 다음 단계                        │
└────────────┬───────────────────────────────────────────────┘
             │
             ↓
┌────────────────────────────────────────────────────────────┐
│ 📊 STAGE 6: 종합 점수 계산 (Scoring Pipeline)              │
│ ────────────────────────────────────────────────────────   │
│ 가중치 시스템 (총 90점 만점)                              │
│                                                            │
│ 1️⃣  용신 적합도 (45%) - 최우선 요소                        │
│    • 용신 오행 매칭도                                     │
│    • 보조 용신 고려                                       │
│    • 오행 균형도                                          │
│                                                            │
│ 2️⃣  음양오행 (15%)                                        │
│    • 획수 음양 균형                                       │
│    • 오행 상생 패턴                                       │
│    • 상극 페널티                                          │
│                                                            │
│ 3️⃣  발음 품질 (15%)                                       │
│    • 발음 자연스러움                                      │
│    • 초성 조합 난이도                                     │
│    • 받침 호환성                                          │
│                                                            │
│ 4️⃣  의미 + 가치 (15%)                                     │
│    • 한자 의미 품질                                       │
│    • 부모 가치관 정렬                                     │
│    • 의미 조화                                            │
│                                                            │
│ 5️⃣  획수/수리 (0%) - 비활성화                             │
│    • 데이터 부정확으로 가중치 0                           │
│                                                            │
│ 🚨 금기 감점 (별도 처리)                                   │
│    • Critical 한자: -40점                                 │
│    • High severity: -20점                                 │
│    • Medium severity: -10점                               │
│                                                            │
│ 🎁 보너스 점수 (+5점 조건부)                               │
│    • 음양오행 ≥ 90점                                      │
│    • 발음 품질 ≥ 90점                                     │
│    • 의미 품질 ≥ 80점                                     │
│    → 모두 충족 시 +5점                                    │
│                                                            │
│ 💯 최종 점수 범위: 80-100점                                │
│                                                            │
│ Output: 점수 포함된 이름 후보                             │
└────────────┬───────────────────────────────────────────────┘
             │
             ↓
┌────────────────────────────────────────────────────────────┐
│ 🔍 STAGE 7: 필터링                                          │
│ ────────────────────────────────────────────────────────   │
│ • 최소 점수: 80점 이상만 통과                             │
│ • 용신 필수 매칭 확인                                     │
│ • 흉수(凶數) 제외                                         │
│                                                            │
│ Output: 고품질 이름만 선별                                │

             │
             ↓
┌────────────────────────────────────────────────────────────┐
│ 🏆 STAGE 8: 랭킹 & 반환                                     │
│ ────────────────────────────────────────────────────────   │
│ • 점수 내림차순 정렬                                      │

## 2. 개명 서비스 (Renaming)

### 📍 라우트 구조
- `/renaming` - 정보 입력
- `/renaming/analysis` - 현재 이름 분석
- `/renaming/results` - 개명 추천
- `/renaming/experts` - 전문가 제안 (개발 예정)

### 🔄 워크플로우

```
┌─────────────────────────────────────────────────────────────────┐
│                    개명 서비스 워크플로우                        │

┌────────────────────────────────┐
│ 👤 사용자 입력                 │
│ ─────────────────────────────  │
│ • 현재 이름: 한글 + 한자       │
│ • 생년월일시                   │
│ • 성별                         │
│ • 개명 사유 (선택)             │

             │

#### 2. 용신 분석 (Yongsin Analyzer)

```typescript
// app/lib/saju/yongsin-analyzer.ts

알고리즘: 5방법 + AI 종합
──────────────────────────

입력: SajuResult (4기둥 + 오행 분포)
출력: 용신(主) + 보조 용신(副)

방법 1: 억부법(抑扶法) - 강약 균형
─────────────────────────────────
• 일간(본인) 강함 → 설기(泄氣) 오행 (약화)
• 일간(본인) 약함 → 생조(生助) 오행 (강화)

예: 일간 = 土, 오행 분포 = 土 1개, 水 3개
→ 본인 약함 → 생조 필요 → 火 (생토) 용신

방법 2: 조후법(調候法) - 계절 조화
─────────────────────────────────
• 여름생 + 火 많음 → 水 (냉각)
• 겨울생 + 水 많음 → 火 (온난)

방법 3: 통관법(通關法) - 충돌 완화
─────────────────────────────────
• 金 ⚔ 木 충돌 → 水 (金生水生木)
• 水 ⚔ 火 충돌 → 木 (水生木生火)

방법 4: 병약법(病藥法) - 문제 해결
─────────────────────────────────
• 금기 한자 있음 → 중화 오행
• 상극 심함 → 균형 오행

방법 5: 전왕법(專旺法) - 특화 강화
─────────────────────────────────
• 한 오행 극강 (≥60%) → 그 오행 강화

AI 통합 분석:
─────────────
• OpenAI GPT-4 호출
• 5가지 방법 결과 제공
• 우선순위 결정 요청
• 용신(主) + 보조 용신(副) 추천

최종 결과:
• 용신(主): FIRE
• 보조(副): WOOD
• 신뢰도: 0.85
```

// app/lib/naming/scorers/scoring-pipeline.ts

알고리즘: 가중치 기반 종합 점수
────────────────────────────────

입력: NameCandidate (이름 후보)
출력: 0-100점 최종 점수

1️⃣  용신 적합도 (45% 가중치)
──────────────────────────
• 이름 한자의 오행 추출
• 용신 매칭 비율 계산
  - 100% 매칭: 만점
  - 50% 매칭: 절반
  - 0% 매칭: 0점
• 보조 용신 고려 (+10%)

점수 = (매칭_비율 * 0.45 * 100)
예: 2자 모두 FIRE, 용신 FIRE → 100 * 0.45 = 45점

2️⃣  음양오행 (15% 가중치)
──────────────────────────
• 획수 음양 체크 (홀=양, 짝=음)
• 균형도 평가:
  - 이상적: 양-음-양 또는 음-양-음
  - 불균형: 양-양-양 또는 음-음-음
• 오행 상생 보너스
• 오행 상극 페널티

점수 = (균형도 * 0.15 * 100)

3️⃣  발음 품질 (15% 가중치)
──────────────────────────
• 초성-중성-종성 자연스러움
• 받침 조합 난이도
  - 쉬움: ㄴ,ㅁ,ㅇ,ㄹ
  - 어려움: ㄲ,ㅃ,ㅆ,ㅉ,ㄸ
• 같은 음절 반복 페널티 (-10점)
• 발음 유사도 체크

점수 = (자연스러움 * 0.15 * 100)

4️⃣  의미 품질 (15% 가중치)
──────────────────────────
• 한자 의미 분석
• 부모 가치관 정렬 (+5점)
  - 가치: "성실", "책임감"
  - 한자 의미 매칭
• 의미 조화도 평가

점수 = (의미_품질 * 0.15 * 100)

5️⃣  획수/수리 (0% 가중치) ⚠️  비활성화
────────────────────────────────────
• 데이터 부정확으로 가중치 0
• 향후 DB 개선 후 활성화 예정

🚨 금기 감점 (별도 처리)
──────────────────────────
• EXPLICIT 금기 (12개): -100점 (차단)
• Critical severity: -40점
• High severity: -20점
• Medium severity: -10점

🎁 보너스 점수 (조건부 +5점)
──────────────────────────────
조건:
• 음양오행 점수 ≥ 90점
• 발음 품질 점수 ≥ 90점
• 의미 품질 점수 ≥ 80점
→ 모두 충족 시 +5점 추가

최종 점수 계산:
────────────────
기본 점수 = 용신(45) + 음양(15) + 발음(15) + 의미(15)
          = 최대 90점

최종 점수 = 기본 점수 - 금기 감점 + 보너스
          = 80-100점 범위
```

// app/lib/naming/filters/taboo-rules.ts

알고리즘: 다층 안전 필터
──────────────────────────

─────────────────────────────────
성씨: 김, 이, 박, 최, 정, 강, 조, 윤, 장, 임, 한, 오, 서, 신, 권, ...
처리: 이름으로 사용 불가 (성과 이름 혼동 방지)
예외: 일부 일반 한자는 허용 (예: 民, 英)

Layer 3: Severity 기반 필터링
─────────────────────────────

  - 예: 死, 亡, 凶, 殺, 盜

  - 예: 病, 貧, 弱, 愚, 醜

• MEDIUM: 중간 페널티 (-10점)
  - 예: 暗, 悲, 孤, 寒

Layer 4: Early Filtering (성능 최적화)
─────────────────────────────────────
타이밍: Stage 3 (한자 추천) 직후
대상: EXPLICIT + CRITICAL + HIGH
효과: 조합 생성 전 차단 (불필요한 계산 방지)

점수 계산 시점 체크:
───────────────────
타이밍: Stage 6 (점수 계산)
대상: MEDIUM severity
효과: 점수 감점 처리

결과:
─────
• 안전한 이름만 최종 추천
• 다층 방어로 누락 방지
• 성능과 안전성 균형
```
