## 적용 방법

### 1. 데이터베이스 업데이트

```bash
# TypeScript 스크립트 실행
npx tsx scripts/update-negative-hanja-expanded.ts
```

### 2. 작명 시스템 통합

이 한자들은 `isGoodForNaming = false`로 표시되어 자동으로 필터링됩니다:

```typescript
// 작명용 한자만 조회
const suitableHanja = await prisma.hanjaDict.findMany({
  where: {
    isGoodForNaming: true,
    element: targetElement, // 필요한 오행
  },
});
```
