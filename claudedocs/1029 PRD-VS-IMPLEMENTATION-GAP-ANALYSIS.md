## 1. 제품 비전 & 타겟 시장

### PRD 계획
```
타겟: 외국인 (K-pop 팬, 국내 거주 외국인, 재외동포)
언어: 9개 언어 지원
핵심 가치: AI + 전통 철학 융합 (외국인 맞춤)
```

### 실제 구현
```
타겟: **한국인** (신생아 작명, 개명)
언어: **한국어만** (다국어 미구현)
핵심 가치: **전통 사주 + AI** (한국인 중심)
```

### 부합도: ❌ **0%** - **완전히 다른 방향**

**차이점**:
1. **타겟 고객이 정반대**
   - PRD: 외국인을 위한 한국 이름
   - 실제: 한국인을 위한 전통 작명

2. **언어 지원**
   - PRD: 9개 언어 (영어, 중문, 일문 등)
   - 실제: 한국어 only

3. **서비스 철학**
   - PRD: "외국인도 이해 가능한 교육적"
   - 실제: "전통 명리학 전문가 수준"

**분석**:
> 프로젝트가 **완전히 다른 방향으로 피벗**했습니다.
> 외국인 대상 → 한국 내수 시장 전환.
> 이는 시장 검증 결과일 가능성이 높습니다.

## 7. 알고리즘 비교

### 7.1 작명 플로우

#### PRD 계획 (12단계)
```
1. 사주팔자 계산 (0.1초)
2. 용신 분석 (2-3초) ⭐ AI
3. 오행 분석 (0.05초)
4. 희신 결정 (1-2초) ⭐ AI
5. 발음 매칭 (0.5초) ← IPA 변환!
6. 한자 후보 (0.1초)
7. 의미 매칭 (3-4초) ⭐ AI
8. 조합 생성 (0.2초)
9. 음양 검증 (0.1초)
10. 81수리 (0.05초)
11. 종합 점수 (0.1초)
12. 순위 정렬 (즉시)

총 소요: ~10초
```

#### 실제 구현 (8단계)
```
1. 사주 계산 (SajuCalculator)
2. 용신 분석 (YongsinAnalyzer) ⭐ AI
3. 한자 추천 (HanjaMatcher - DB 쿼리)
4. 조합 생성 (최대 10,000개)
5. 검증 (Yin-Yang, Phonetic, Numerology81)
6. 점수 계산 (5개 Scorer 병렬)
7. 필터링 (minScore >= 60, 상위 20개)
8. Freemium 분류 (locked 1-10위, free 11-12위)

목표 소요: < 10초
```

**부합도**: ✅ **85%** (핵심 흐름 일치, 발음 매칭만 다름)

**차이점**:
1. **단계 수**: 12 → 8 (더 간결하게 통합)
2. **발음 매칭**: IPA 변환 (외국인용) → 음운 조화 (한국어)
3. **Freemium**: PRD에 없던 추가 단계!

### 7.2 점수 계산

#### PRD
```typescript
totalScore =
  yongsinScore * 0.35 +
  yinyangScore * 0.25 +
  phoneticScore * 0.20 + // IPA 유사도
  semanticScore * 0.10 +
  numerologyScore * 0.05 +
  forbiddenScore * 0.05;
```

#### 실제
```typescript
totalScore =
  ElementScorer * 0.35 +       // 용신 매칭
  YinYangScorer * 0.25 +       // 음양 균형
  PhoneticScorer * 0.20 +      // 음운 조화 (한글)
  MeaningScorer * 0.10 +       // 의미 분석

```

**부합도**: ✅ **95%** (가중치 동일, 의미만 다름)

- 글로벌 블루오션 → 한국 레드오션
- 하지만 **품질 차별화** 가능 (AI + 전통)

### 10.2 수익성 비교
