### Issue #1: 결제 성공 후 잠금 해제 로직 미구현 ❌

**현재 상황**:
```typescript
// app/routes/api.payment.naming.ts
// ✅ 결제 요청 생성 완료
// ✅ TossPayments 리디렉션 완료
// ❌ 결제 성공 후 unlocked = true 로직 없음!
```

**영향**:
- 사용자가 결제해도 1-10위 잠금 해제 안됨
- **매출은 발생하지만 서비스 제공 안됨** 🚨
- **치명적 비즈니스 이슈**

**해결 방법**:
```typescript
// app/routes/api.payment.success.ts (수정 필요)
// TossPayments 콜백 받은 후:

1. orderId로 NamingPayment 조회
2. paymentKey로 TossPayments 승인 요청
3. 성공 시:
   - payment.status = 'DONE'
   - payment.unlocked = true ← 핵심!
   - payment.paymentKey = paymentKey
4. 리디렉션: /naming/freemium/result?sessionId=xxx&payment=success
```

**우선순위**: 🔴 **최우선 수정 필요**
