## 📋 작업 개요

### 문제 정의

신생아 작명 서비스에서 **"서서(棲栖)"**같은 부자연스러운 이름이 10위(무료)로 생성되는 문제 발견.

**핵심 이슈:**
1. **같은 음절 반복** - "서서", "준준", "하하" 등은 한국 문화적으로 부자연스러움
2. **의미 중복** - "깃들일+깃계할" 같이 같은 의미가 반복되어 이름의 깊이가 없음
3. **오행 편향** - 오행 점수만 100점이면 상위권 진입 (의미나 언어적 자연스러움 무시)

**원인:**
- 시스템이 오행(40%) 중심으로 점수 계산
- 언어적 자연스러움이나 의미 다양성을 전혀 고려하지 않음
- 획수 기반 NumerologyScorer(20%)도 부정확한 데이터로 작동

### 3. **LinguisticScorer 생성** (30% 가중치)

**신규 파일:** `/app/lib/naming/scorers/linguistic-scorer.ts`

#### 점수 로직:

```typescript
Base Score: 70점

패널티:
1. 같은 음절 반복 (예: "서서", "준준") → -50점
2. 의미 매우 유사 (similarity ≥ 0.7) → -20점
3. 의미 부분 유사 (similarity ≥ 0.4) → -10점
```

#### 테스트 결과:

| 케이스 | 음절 | 의미 | 점수 | 가중 점수 |
|--------|------|------|------|----------|
| ❌ 서서 | 서+서 | 깃들일+깃계할 | 20점 | 6.0점 |
| ❌ 준준 | 준+준 | 준수할+준수하다 | 20점 | 6.0점 |
| ⚠️ 유온 | 유+온 | 부드러울+온화할 | 70점 | 21.0점 |
| ✅ 유진 | 유+진 | 있을+참 | 70점 | 21.0점 |

**점수 차이:** 같은 음절 반복 이름은 완벽한 이름보다 **15점 낮음**

### 4. **의미 유사도 알고리즘** (Jaccard Similarity)

**신규 파일:** `/app/lib/naming/utils/meaning-similarity.ts`

#### 알고리즘:

```typescript
1. 전처리
   "깃들일/깃계할" → ["깃들일", "깃계할"]

2. Jaccard 유사도 계산
   similarity = |A ∩ B| / |A ∪ B|
   범위: 0.0 (완전히 다름) ~ 1.0 (동일)

3. 패널티 매핑
   - ≥ 0.7: 매우 유사 → -20점
   - 0.4~0.7: 부분 유사 → -10점
   - < 0.4: 다양함 → 0점
```

#### 성능:
- 시간 복잡도: O(n + m)
- 응답 시간: < 1ms/쌍
- 배치 처리: 1000쌍 < 1초
