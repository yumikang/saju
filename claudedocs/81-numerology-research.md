## Historical Background

### Origin

The 81수리 system was created by **Chae Gu-bong (채구봉)**, also known as **Seo-san (西山)**, a scholar from the Song Dynasty. He developed the **81수원도 (八十一數元圖)** - the "81 Number Origin Chart" - to explain fortune and misfortune based on Chinese character stroke counts.

### Fundamental Principle

The system analyzes names by:
1. Counting the strokes of Chinese characters (한자/Hanja) used in a name
2. Calculating various "grids" (격) from combinations of these stroke counts
3. Evaluating each grid number against the 81 fortune classifications
4. Determining overall life fortune based on the pattern of auspicious/inauspicious numbers

### Philosophy

The 81수리 system is based on the belief that:
- Names carry vibrational energy that influences destiny
- Character stroke counts encode numerical patterns
- These patterns correspond to universal principles of fortune
- Proper name selection can enhance favorable outcomes and mitigate misfortune

## Four Grids System (사격/오격)

### Korean vs Chinese Terminology

The Korean naming system uses terminology derived from Chinese naming science (姓名學). There are variations in terminology:

**Korean Traditional Terms (사격 - Four Grids):**
- 원격 (元格) - Origin Grid [corresponds to 천격 - Heaven Grid]
- 형격 (亨格) - Prosperity Grid [corresponds to 인격 - Person Grid]
- 이격 (利格) - Benefit Grid [corresponds to 지격 - Earth Grid]
- 정격 (貞格) - Integrity Grid [corresponds to 총격 - Total Grid]

**Chinese Terms (오격 - Five Grids):**
- 천격 (天格) - Heaven Grid
- 인격 (人格) - Person Grid
- 지격 (地格) - Earth Grid
- 총격/총격 (總格) - Total Grid
- 외격 (外格) - Outer Grid

**Note**: The Korean system traditionally emphasizes four grids (원형이정 - 元亨利貞, derived from I Ching principles), while the Chinese system uses five grids. Modern Korean naming services often use both systems or the five-grid system.

### Five Grids Calculation Methods

For a typical Korean three-character name format: **[Surname] [First Name Character] [Second Name Character]**

Example: **이정무 (李正武)** - Li (7 strokes) + Jeong (5 strokes) + Mu (8 strokes)

#### 1. 천격 (Heaven Grid) - 天格
**Represents**: Family background, ancestral fortune, childhood (ages 1-17)
**Influence**: Predetermined by surname, affects early life, family circumstances

**Calculation**:
- **Single surname**: Surname strokes + 1
- **Compound surname**: Add both surname characters' strokes

**Example**:
- 이정무 (李正武): 7 + 1 = **8** (Heaven Grid)
- 司馬光: 5 + 10 = **15** (Heaven Grid)

**Note**: Heaven Grid is considered less influential as it's predetermined by family name.

#### 2. 인격 (Person Grid) - 人格 ⭐ MOST IMPORTANT
**Represents**: Core personality, main fortune, prime of life (ages 17-32)
**Influence**: PRIMARY indicator of fortune, affects entire life trajectory, personality, success

**Calculation**:
- Add the **last character of surname** + **first character of given name**

**Example**:
- 이정무 (李正武): 7 + 5 = **12** (Person Grid)
- 司馬懿: 10 + 22 = **32** (Person Grid)

**Importance**: This is considered the **주운 (主運)** - Principal Fortune - and has the greatest impact on one's destiny.

#### 3. 지격 (Earth Grid) - 地格
**Represents**: Foundation, youth fortune, early career (before age 36)
**Influence**: Affects childhood through early adulthood, educational success, early career

**Calculation**:
- **Two-character given name**: Add both given name characters
- **Single-character given name**: Given name strokes + 1

**Example**:
- 이정무 (李正武): 5 + 8 = **13** (Earth Grid)
- 王華: 15 + 1 = **16** (Earth Grid)

**Note**: Represents the foundation and potential for growth in early life.

#### 4. 총격 (Total Grid) - 總格
**Represents**: Overall life fortune, later life (ages 36-48+), cumulative destiny
**Influence**: Long-term fortune, later years, overall life achievement

**Calculation**:
- Add **all characters** (surname + given name)

**Example**:
- 이정무 (李正武): 7 + 5 + 8 = **20** (Total Grid)
- 司馬懿: 5 + 10 + 22 = **37** (Total Grid)

**Importance**: Indicates the cumulative effect of all fortunes over a lifetime.

#### 5. 외격 (Outer Grid) - 外格
**Represents**: Social relationships, external influences, reputation (ages 33-48)
**Influence**: Social standing, how others perceive you, external opportunities

**Calculation**:
- **Single surname, two-character name**: Total Grid - Person Grid + 1
- **Compound surname**: Total Grid - Person Grid
- **Single surname, single name**: Always **2**

**Example**:
- 이정무 (李正武): 20 - 12 + 1 = **9** (Outer Grid)
- 司馬懿: 37 - 32 = **5** (Outer Grid)
- 王華: **2** (Outer Grid - fixed for single-character names)

**Alternative calculation**: Last character of surname strokes + last character of given name strokes + 1

**Note**: Represents the sphere of social influence and external relationships.

### Life Stage Correspondence

| Grid | Korean | Chinese | Life Stage | Age Range | Importance |
|------|--------|---------|------------|-----------|------------|
| 원격/천격 | 元格 | 天格 | Childhood/Family | 0-17 | Low (predetermined) |
| 형격/인격 | 亨格 | 人格 | Prime/Core | 17-32 | ⭐ HIGHEST (main fortune) |
| 이격/지격 | 利格 | 地格 | Youth/Foundation | 1-36 | Medium-High |
| - / 외격 | - | 外格 | Social/External | 33-48 | Medium |
| 정격/총격 | 貞格 | 總格 | Overall/Later Life | 36+ | High |

### Relative Importance Ranking

1. **인격 (Person Grid)** - 40% influence - Primary determinant of fortune
2. **지격 (Earth Grid)** - 25% influence - Foundation and early development
3. **총격 (Total Grid)** - 20% influence - Overall life trajectory
4. **외격 (Outer Grid)** - 10% influence - Social circumstances
5. **천격 (Heaven Grid)** - 5% influence - Family background (predetermined)

### Ideal Name Characteristics

**Principle**: All grids should contain 길수 (auspicious numbers), especially:
- 인격 (Person Grid) MUST be 대길 or 길
- 지격 (Earth Grid) should be 길 or better
- 총격 (Total Grid) should be 길 or better
- Avoid 대흉 (great misfortune) numbers in any grid

**Warning**: If 2 or more grids have 흉 (inauspicious) or 대흉 (great misfortune) numbers, the negative effect compounds and intensifies.

### Calculation Example - Complete Analysis

**Name**: 김민수 (金敏秀)
- 김 (金) = 8 strokes
- 민 (敏) = 11 strokes
- 수 (秀) = 7 strokes

**Grid Calculations**:
1. **천격 (Heaven Grid)**: 8 + 1 = **9** → 대흉 (Great Misfortune) ⚠️
2. **인격 (Person Grid)**: 8 + 11 = **19** → 대흉 (Great Misfortune) ⚠️⚠️⚠️
3. **지격 (Earth Grid)**: 11 + 7 = **18** → 대길 (Great Fortune) ✓
4. **총격 (Total Grid)**: 8 + 11 + 7 = **26** → 흉 (Misfortune) ⚠️
5. **외격 (Outer Grid)**: 26 - 19 + 1 = **8** → 길 (Fortune) ✓

**Analysis**:
- ⚠️ Critical problem: 인격 (Person Grid = 19) is 대흉 - the most important grid is inauspicious!
- ⚠️ Three grids (천격, 인격, 총격) are inauspicious
- ✓ Only two grids (지격, 외격) are favorable
- **Verdict**: This name is NOT recommended due to critical 인격 misfortune

## Stroke Counting Rules

### Basic Principle: 원획법 (Original Stroke Method)

Korean naming science uses **원획법 (元劃法)** - the Original Stroke Method, which counts strokes based on the **original form** of radicals as documented in the **강희자전 (Kangxi Dictionary 康熙字典)**, NOT the simplified or written form.

This differs from **필획법 (筆劃法)** - Written Stroke Method, which counts strokes as they appear visually.

### Why Kangxi Dictionary?

The 강희자전 (康熙字典) is considered the authoritative reference because:
- Most comprehensive classical Chinese character dictionary
- Standardizes stroke counts for tens of thousands of characters
- Preserves original forms and meanings of radicals
- Historical authority in East Asian naming traditions

**Critical Rule**: Some characters appear to have fewer strokes than their actual count according to Kangxi standards.

## Five Elements Theory (오행)

### Overview

The **오행 (五行)** - Five Elements theory is an integral part of Korean naming science, working alongside the 81수리 system. It adds another layer of analysis based on elemental balance and harmony.

### The Five Elements

| Element | Korean | Character | Nature | Season | Direction |
|---------|--------|-----------|--------|--------|-----------|
| Wood | 목 (木) | 木 | Growth, expansion | Spring | East |
| Fire | 화 (火) | 火 | Heat, ascending | Summer | South |
| Earth | 토 (土) | 土 | Stability, center | Late Summer | Center |
| Metal | 금 (金) | 金 | Consolidation, contraction | Autumn | West |
| Water | 수 (水) | 水 | Flowing, descending | Winter | North |

### Interaction Cycles

**생 (生) - Generation/Production Cycle** (Constructive):
- Wood generates Fire (木生火)
- Fire generates Earth (火生土)
- Earth generates Metal (土生金)
- Metal generates Water (金生水)
- Water generates Wood (水生木)

**극 (克) - Conquest/Destruction Cycle** (Destructive):
- Wood conquers Earth (木克土)
- Earth conquers Water (土克水)
- Water conquers Fire (水克火)
- Fire conquers Metal (火克金)
- Metal conquers Wood (金克木)

### Stroke Count to Five Elements

Elements are assigned based on the **last digit** of the stroke count:

| Last Digit | Element | Korean |
|------------|---------|---------|
| 1, 2 | Wood | 목 (木) |
| 3, 4 | Fire | 화 (火) |
| 5, 6 | Earth | 토 (土) |
| 7, 8 | Metal | 금 (金) |
| 9, 0 | Water | 수 (水) |

**Examples**:
- 7 strokes → 7 → Metal (금)
- 12 strokes → 2 → Wood (목)
- 25 strokes → 5 → Earth (토)
- 38 strokes → 8 → Metal (금)
- 50 strokes → 0 → Water (수)

### Five Elements in Name Grids

Apply five elements analysis to the grids:

1. **천격 (Heaven Grid)** → Element A
2. **인격 (Person Grid)** → Element B (most important!)
3. **지격 (Earth Grid)** → Element C
4. **총격 (Total Grid)** → Element D
5. **외격 (Outer Grid)** → Element E

### Ideal Element Relationships

**Best (상생 - Mutual Generation)**:
- Each grid should **generate** (생) the next
- Example: Wood → Fire → Earth → Metal → Water

**Acceptable**:
- Compatible or neutral relationships
- Same element is neutral

**Avoid (상극 - Mutual Conquest)**:
- Grids that **conquer** (극) each other
- Especially avoid if 인격 (Person Grid) is conquered

**Critical**: The 인격 (Person Grid) element should ideally:
- Be generated by 천격 (Heaven Grid)
- Generate 지격 (Earth Grid)
- Not be conquered by any other grid

### Sound Five Elements (소리오행 / 발음오행)

In addition to stroke-based elements, Korean naming also considers **sound elements** based on pronunciation:

**Consonant Classification**:

| Element | Korean Consonants (초성) |
|---------|-------------------------|
| Wood (목) | ㄱ, ㅋ |
| Fire (화) | ㄴ, ㄷ, ㄹ, ㅌ |
| Earth (토) | ㅇ, ㅎ |
| Metal (금) | ㅅ, ㅈ, ㅊ |
| Water (수) | ㅁ, ㅂ, ㅍ |

**Application Methods** (Competing Theories):

**Method A (초성 only)**:
- Only initial consonants (초성) need to be harmonious
- Final consonants (종성) can be in conflict without issue

**Method B (초성 + 종성)**:
- Both initial and final consonants must be harmonious
- Though initial consonants alone can be in conflict

**Method C (Strictest)**:
- Both Method A and Method B must be satisfied simultaneously

**Modern Consensus**:
- Most naming consultants prioritize **initial consonants** (초성)
- The three name positions (surname, first character, second character) should follow 상생 (generation cycle)
- Example: Wood (ㄱ surname) → Fire (ㄴ first name) → Earth (ㅇ second name) = Good!

### Integration: 81수리 + Five Elements

**Complete Name Analysis** requires checking:

1. **81수리 (Numerology)**: All grids should be 길수 (auspicious numbers)
2. **오행 (Five Elements - Strokes)**: Grids should follow generation cycle or be compatible
3. **소리오행 (Sound Elements)**: Initial consonants should follow generation cycle
4. **사주 보완 (Saju Complement)**: Name should balance birth chart weaknesses

**Ideal Name Characteristics**:
- ✓ All grids are 길 (fortune) or 대길 (great fortune) in 81수리
- ✓ Elements follow 상생 (generation) relationships
- ✓ Initial consonants follow generation cycle
- ✓ Complements weak elements in birth chart (사주)
- ✓ Beautiful meaning and appropriate for gender
- ✓ Easy to read and pronounce

// Calculate five grids from name
function calculateGrids(surname, firstName, secondName) {
  const surnameStrokes = getStrokeCount(surname);
  const firstStrokes = getStrokeCount(firstName);
  const secondStrokes = getStrokeCount(secondName);

  return {
    heavenGrid: surnameStrokes + 1, // 천격
    personGrid: surnameStrokes + firstStrokes, // 인격 (most important!)
    earthGrid: firstStrokes + secondStrokes, // 지격
    totalGrid: surnameStrokes + firstStrokes + secondStrokes, // 총격
    outerGrid: (surnameStrokes + firstStrokes + secondStrokes) - (surnameStrokes + firstStrokes) + 1 // 외격
  };
}

// Get fortune level for a grid number
function getFortuneLevel(gridNumber) {
  if (gridNumber > 81) {
    gridNumber = gridNumber % 80; // Wrap around for numbers > 81
    if (gridNumber === 0) gridNumber = 80;
  }
  return fortune81Table[gridNumber];
}

### Best Practices for Name Selection

1. **Priority Order**:
   - ① 인격 (Person Grid) MUST be 대길 or 길
   - ② 지격 (Earth Grid) should be 길 or better
   - ③ 총격 (Total Grid) should be 길 or better
   - ④ Minimize 흉 numbers in any grid
   - ⑤ Consider five elements harmony

2. **Critical Numbers to Avoid**:
   - Never use 34 in any grid (most inauspicious)
   - Avoid 2, 4, 9, 10, 19, 20, 22, 44, 50, 54, 70 especially in 인격
   - If 2+ grids are 흉 or 대흉, reject the name

3. **Element Considerations**:
   - Check birth chart (사주) for elemental weaknesses
   - Choose stroke counts that provide missing elements
   - Ensure 인격 element is not conquered by other grids

4. **Sound Harmony**:
   - Initial consonants should follow generation cycle
   - Avoid awkward pronunciation combinations
   - Consider regional dialect variations

5. **Practical Factors**:
   - Meaning should be appropriate and positive
   - Consider gender appropriateness
   - Check for unfortunate homonyms
   - Ensure name works in professional contexts
   - Consider international usability if relevant
